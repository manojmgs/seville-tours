## Getting Started

Install dependencies and run the development server with Node's system CA store enabled:

```powershell
pnpm install
$env:NODE_OPTIONS="--use-system-ca"
pnpm dev
```

Always enable `--use-system-ca` for local development. The FareHarbor and Parausted
server-side integrations require Node to trust certificates installed in the Windows
certificate store. Do not use `NODE_TLS_REJECT_UNAUTHORIZED=0`; it disables TLS
certificate verification instead of extending Node's trusted certificate authorities.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
